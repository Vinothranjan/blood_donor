STEP 1: INSTALL ENVIRONMENT DEPENDENCIES
------------------------------------------------------------------------------
Open Terminal / Command Prompt in the project folder and run:

py -m pip install -r requirements.txt


STEP 2: LAUNCH THE APPLICATION SERVER
------------------------------------------------------------------------------
Option A (Recommended — Auto-Port Assignment & No-Cache Dev Server):
    python serve.py
    (or: py serve.py)

Option B (Standard Python HTTP Server):
    python -m http.server 8000
    (or: py -m http.server 8000)

Option C (Direct Browser Launch):
    Double-click `index.html` to open directly in any modern browser.


STEP 3: OPEN IN BROWSER
------------------------------------------------------------------------------
Open your web browser and navigate to:
    http://localhost:8000  (or http://127.0.0.1:8000)
